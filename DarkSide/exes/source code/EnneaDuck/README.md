# EnneaDuck

A fun desktop pet application featuring an animated duck that follows your mouse, tells jokes, and provides entertainment.

## Features

- Animated duck that follows your mouse cursor
- Random jokes and dark humor
- Multiple animations (idle, walking, rotating, etc.)
- Sound effects with volume control
- Multi-monitor support
- Right-click menu for additional options

## Installation

1. Ensure you have Python 3.7+ installed
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the application:
```bash
python EnneaDuck.py
```

### Controls

- Left-click and drag to move the duck window
- Right-click for menu options
- Mouse hover for interaction
- Click the duck for random jokes

## Project Structure

- `EnneaDuck.py` - Main entry point
- `config.py` - Configuration settings
- `utils.py` - Utility functions
- `gui.py` - Main GUI implementation
- `animation.py` - Animation handling
- `popup.py` - Popup menu implementation
- `sync.py` - Sync functionality
- `audio/` - Sound effect files
- `images/` - Animation image files

## Configuration

Edit `config.py` to customize:
- Window size
- Animation speed
- Sound volume
- Movement parameters
- Joke frequency
